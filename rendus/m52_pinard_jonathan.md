## Mon sujet d'étude est CS50P – Introduction to Programming with Python (Harvard / edX)

**_Décrire le sujet_**

_Le sujet doit être en lien avec votre Travail de Bachelor, avec une composante "technique". Ce cours doit vous permettre, concrètement, de monter en puissance sur un sujet utile pour votre TB._

CS50P est une formation gratuite proposée par l'Université Harvard sur la plateforme edX. Elle couvre les fondamentaux du langage Python en neuf semaines : types de données, structures de contrôle, fonctions, bibliothèques standard, manipulation de fichiers, expressions régulières, tests unitaires, programmation orientée objet et manipulation de données externes (CSV, SQL). Chaque semaine s'accompagne d'un problem set évalué directement sur la plateforme. Le cours se conclut par un projet final autonome, qui constitue la validation concrète de l'acquisition des compétences.

La composante technique est centrale : il ne s'agit pas d'une formation passive. Chaque concept est immédiatement mis en pratique via des exercices de difficulté progressive, corrigés automatiquement. L'environnement de travail est celui du développeur Python : terminal, éditeur de code, outils de test.

## 5 questions

_Rédigez 5 questions qui devront vous permettre de tester l'acquisition des nouvelles compétences._

**Question 1**
En Python, quelle est la différence entre une exception levée par `raise` et une exception non gérée, et dans quel cas utiliser un bloc `try/except/finally` plutôt qu'une simple vérification de condition (`if/else`) pour gérer un cas d'erreur ?

**Question 2**
Comment structurer une suite de tests unitaires avec pytest pour une fonction Python qui lit un fichier CSV et retourne un dictionnaire, de façon à couvrir à la fois le cas nominal, le fichier manquant, et le fichier malformé ?

**Question 3**
Quelle est la différence entre une classe Python et un module Python, et dans quel cas est-il plus adapté de modéliser un concept comme une classe avec ses méthodes plutôt que comme un ensemble de fonctions dans un module ?

**Question 4**
Comment Python gère-t-il les expressions régulières via le module `re`, et quelle est la différence pratique entre `re.search()`, `re.match()` et `re.findall()` lors de l'analyse d'un texte non structuré comme un log d'application ?

**Question 5**
Dans un contexte d'agent IA Python qui communique avec une API externe, comment organiser la structure du code pour garantir la testabilité, la lisibilité et la maintenabilité du projet à moyen terme grâce a l'architecture en microservices, permettant de créer des outils modulables dans le temps ?
